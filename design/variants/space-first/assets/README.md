# Assets for the space-first prototype

Every image here is NASA data or made by TrueSouth's pipeline from NASA data. Nothing was
retouched, painted or generated by AI. Images were only resized, cropped, split or
re-encoded. The script that made them is [`../tools/make_assets.py`](../tools/make_assets.py).

The folder weighs 9.5 MB. Every file is under 1.6 MB.

| `moon_height_1440.png` | 0.49 MB | https://svs.gsfc.nasa.gov/vis/a000000/a004700/a004720/ldem_4.tif (LOLA heights in km, 4 pixels per degree) | Heights −9.0 to +10.6 km mapped to 0–255, 8-bit greyscale PNG, 1,440 × 720. All three maps are equirectangular with 0° longitude at the centre. Credit: NASA's Scientific

Check: Shackleton's 20.9 km rim, drawn at its IAU position with the §2.3 formulas, sits
exactly on the crater in `hillshade_core_2048.webp`, and Connecting Ridge falls on the ridge
between Shackleton and de Gerlache.

## The ground around each polar site

| File | Size | Source | What was done |
| :--- | ---: | :--- | :--- |
| `terrain_cr.bin`, `terrain_mal.bin`, `terrain_mou.bin`, `terrain_dgr.bin` | 0.18 MB each | NASA LOLA 80 m map `LDEM_80S_80MPP_ADJ` (the pipeline's prepared copy, read only) | For each site, heights sampled (bilinear) on a 257 × 257 grid over a 20 km square (§13), then on a 161 × 161 grid over a 300 km square from a 640 m block-mean copy. Grid points found by walking from the site (§2.2) and projecting (§2.3). Stored as little-endian uint16, (height in m + 12,000) × 2, rows north to south: the patch first, then the apron. |
| `terrain.json` | 1 KB | Same | Each site's latitude, longitude, height at the site and the encoding. |

Apollo 11 has no file: it is a sphere-tier site with no terrain data.
